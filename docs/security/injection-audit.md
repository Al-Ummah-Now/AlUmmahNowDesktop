# Injection Security Audit — AlUmmahNowDesktop

Audit scope: `AlUmmahNow.App`, `AlUmmahNow.CoreBridge`, `AlUmmahNow.CoreBridge.Native`, `AlUmmahNow.Studio`, `AlUmmahNow.Admin`, Windows (WinUI 3), Linux (GTK 4), and Tizen targets.

## Findings

| Component | Input | Risk | Status | Regression Test |
|---|---|---|---|---|
| `ShellBrowserLauncher.Open` (`CoreRuntime.cs`) | `Uri` opened via `Process.Start(..., UseShellExecute = true)` | Arbitrary OS URI/file handler execution (`file://`, `ms-msdt:`, `javascript:`) | Fixed (`IsAllowedUri` enforces absolute `http(s)` without control chars) | `tests/AlUmmahNow.CoreBridge.Native.Tests/InjectionAuditTests.cs::ShellBrowserLauncher_allows_only_http_and_https_uris` |
| `GstPipeline.Build` & `RungPipeline.Build` (`Encoding.cs`, `RenditionEncoding.cs`) | Source/output file paths, `encoder.Name`, `rung.Profile` | Backslash-quote (`\"`) broke out of GStreamer `gst_parse_launch` string literal; unvalidated element/profile names could inject pipeline elements | Fixed (escape `\` before `"`, reject CR/LF/NUL, validate `[A-Za-z0-9_-]+` for element/profile) | `tests/AlUmmahNow.Studio.Tests/InjectionAuditTests.cs::GstPipeline_and_RungPipeline_escape_backslashes_and_reject_injected_elements` |
| `CsvWriter.Field` (`CsvWriter.cs`) | Video titles & exported analytics cells | CSV formula injection bypass via leading spaces (`" =CMD|..."`) or leading `\n` (`"\n=1+1"`) | Fixed (checks leading newline and first non-space trigger character while preserving negative numbers) | `tests/AlUmmahNow.Studio.Tests/InjectionAuditTests.cs::CsvWriter_neutralizes_leading_whitespace_and_newline_formula_injection` |
| `StudioHttpClient` (`StudioHttpClient.cs`) | Relative API paths & HTTP 3xx redirects | `new Uri(_base, path)` allowed absolute/scheme-relative paths to send Bearer token to foreign hosts; default `HttpClient` followed redirects | Fixed (`AllowAutoRedirect = false`, relative-path check + `SameOrigin` guard) | `tests/AlUmmahNow.Studio.Tests/InjectionAuditTests.cs::StudioHttpClient_refuses_absolute_and_cross_origin_paths` |
| `HttpCatalogClient`, `HttpLiveClient`, `HttpNotificationsClient`, `HttpEventsClient` | Video/stream IDs, relative paths, subtitle text URLs | `Uri.EscapeDataString("..")` returns `".."` (path traversal); `new Uri(baseUri, path)` could escape base origin; `GetTextAsync` accepted `file://` or cleartext `http://` | Fixed (`SharedHttpHelper.SafePathSegment`, `ResolveSameOrigin`, HTTPS/loopback check in `GetTextAsync`) | `tests/AlUmmahNow.App.Tests/InjectionAuditTests.cs::Temporary_http_clients_reject_dot_segments_and_insecure_text_urls` |
| `AdminApiReviewService` (`AdminApiReviewService.cs`) | Review/install IDs and paths | `Uri.EscapeDataString("..")` caused path traversal; `SendAsync` didn't verify resolved URI remained on `root` origin | Fixed (rejects empty/dot-only IDs in `Id()` and enforces same-origin in `SendAsync`) | `tests/AlUmmahNow.Admin.Tests/InjectionAuditTests.cs::AdminApiReviewService_rejects_dot_segment_ids_without_network_call` |
| `LogScrubber` & `Log.Write` (`LogScrubber.cs`, `Log.cs`) | Log messages & categories | CR/LF and C0 control characters enabled log line forging in `FileLogSink` and stderr | Fixed (`LogScrubber.ScrubLine` neutralizes CR/LF/control/line-separator chars on `Category` and `Message`) | `tests/AlUmmahNow.App.Tests/InjectionAuditTests.cs::LogScrubber_neutralizes_crlf_and_control_char_log_injection` |
| `HlsPlaylist.ParseVariants` (`HlsPlaylist.cs`) | Variant URIs inside HLS master playlists | Arbitrary URI schemes (`file://`, `javascript:`) and `https -> http` downgrades | Fixed (only accepts `https://`, or `http://` when master playlist is `http://`) | `tests/AlUmmahNow.App.Tests/InjectionAuditTests.cs::HlsPlaylist_rejects_non_http_and_downgraded_variant_schemes` |
| `ShortLinks` (`ShortLinks.cs`) | `shortLinkHost` and channel handles | Unvalidated host string interpolated into `https://{host}`; handles allowed `.`/`..` and control chars | Fixed (strict DNS hostname regex on `shortLinkHost`; rejects `.`, `..`, `\`, control chars in handles) | `tests/AlUmmahNow.App.Tests/InjectionAuditTests.cs::ShortLinks_rejects_host_injection_and_dot_or_control_handles` |
| `LoopbackRedirect` & `PkceAuthSession` | OAuth loopback callback requests | Prefix check matched `/auth/callback-evil` and non-GET verbs; `PkceAuthSession` checked `error` before `state` and allowed duplicate params | Fixed (exact `GET /auth/callback` match, `state` checked before `error`, duplicate param rejection) | `tests/AlUmmahNow.Studio.Tests/InjectionAuditTests.cs::LoopbackRedirect_rejects_prefix_spoof_and_non_get_verbs`, `tests/AlUmmahNow.App.Tests/InjectionAuditTests.cs::PkceAuthSession_verifies_state_before_error_and_rejects_duplicate_params` |
| `StagedPackage.Prepare` (`StagedPackage.cs`) | Staged update package `fileName` | Path traversal if `fileName` contained `/` or `..` | Fixed (rejects separators, `.`, `..`, NUL) | `tests/AlUmmahNow.CoreBridge.Native.Tests/InjectionAuditTests.cs::StagedPackage_rejects_path_traversal_filenames` |
| `PrivateFolder`, `SelfUpdater`, `NativePasskeyClient`, `AdminRedirect` | Update folders/redirects, WebAuthn RP ID, `alummahnow-admin://` protocol | Symlink/permission escape, update host spoofing, RP ID spoofing, deep link spoofing | OK (already enforces `PrivateFolder.Ensure`, per-hop `IsAllowed` + SHA-256 + Ed25519, `IsAllowedRpId`, exact `AdminRedirect.IsCallback`) | `tests/AlUmmahNow.CoreBridge.Native.Tests/SelfUpdaterTests.cs`, `tests/AlUmmahNow.Platform.Windows.Tests/PasskeyFlowTests.cs` |
| WebViews / Pango Markup / Local SQL / Process launches | N/A | WebView XSS, Pango markup injection, SQLi, shell injection | OK (no WebViews, no `SetMarkup` calls with untrusted text, no local SQLite/SQL, restart `Process.Start` uses `UseShellExecute = false` with `Environment.ProcessPath`) | N/A |
